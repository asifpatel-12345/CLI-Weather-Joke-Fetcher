# 🌤️🤖 CLI Weather & Joke Fetcher Tool

A lightweight Python command-line tool that interacts with live public APIs to fetch real-time city weather updates and entertaining random jokes with a clean and structured layout.

---

## ✨ Features
- **Live Weather Data:** Fetches real-time temperature, weather conditions, humidity, and wind speed for any city using open-source weather metrics.
- **Random Joke Generator:** Connects to a live joke API to serve fresh setup-and-punchline jokes instantly.
- **Interactive CLI Menu:** User-friendly command-line interface with continuous looping options.
- **Error Handling:** Robust try-except blocks for graceful network error handling and invalid inputs.

---
